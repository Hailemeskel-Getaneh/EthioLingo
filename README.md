EthioLingo is an interactive Ethiopian language learning application (Amharic, Afaan Oromoo, Tigrinya).

## Key Features
- Reusable UI component architecture
- Offline-first SQLite database with Drizzle ORM
- Daily streak tracker and gamified quiz scores
- Centralized Express backend API
